# youtube-topic-filter

Explore ways to restrict YouTube playback to a chosen set of topics — for
example, allowing only soccer or baseball game clips.

## Status

Early planning. No application code yet. See
[`docs-summary.md`](./docs-summary.md) for the problem statement, why the
official YouTube app can't be topic-filtered, the recommended approaches
(curated custom player / channel whitelist / optional classifier), and the
open questions to resolve before implementation.

## Next step

Use `docs-summary.md` as the brief to produce an initial implementation plan.
